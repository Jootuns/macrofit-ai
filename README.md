# MacroFit AI

Aplicación móvil de nutrición y entrenamiento que permite crear planes personalizados, calcular macronutrientes, generar listas de la compra y optimizar el presupuesto del usuario.

## Estado del proyecto

Proyecto en desarrollo.

## Objetivo

Centralizar en una sola aplicación:

- Cálculo de calorías y macronutrientes.
- Planificación personalizada de comidas.
- Generación automática de listas de la compra.
- Comparación de precios entre supermercados.
- Creación de rutinas de entrenamiento.
- Seguimiento del progreso físico.
- Recomendaciones personalizadas mediante inteligencia artificial.
